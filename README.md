# knowledge-catalog

大学知识点归档目录索引 — Catalog of college study knowledge archive

## 说明

本仓库收录一份**知识点归档目录**网页（`知识点归档目录.html`），用于索引按学科分装的大学学习资料压缩包（共三个，各 <1GB）：

- `知识点归档-01.zip`：48 个文件 · 约 660MB（有机化学、金工实习、物理等 12 个学科）
- `知识点归档-02.zip`：125 个文件 · 约 660MB（概率论、化学、微积分等 11 个学科）
- `知识点归档-03.zip`：102 个文件 · 约 660MB（机械、植物学、土壤学等 16 个学科）

网页为单文件自包含（无外部依赖），支持按学科分组浏览、展开折叠、实时搜索文件名或学科，桌面与移动端均可正常使用。双击 `知识点归档目录.html` 即可在浏览器打开。

> 压缩包本体未包含在本仓库内，仅提供目录索引网页。
